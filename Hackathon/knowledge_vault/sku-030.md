# SKU-030 Infusion Set Standard
Summary: SKU-030 Infusion Set Standard: sterile-device product stored at 15-30°C in sealed packaging, supplier SUP-06.

Facts:
- SKU-030 (Infusion Set Standard) must be stored at 15-30°C in sealed packaging.
- SKU-030 (Infusion Set Standard) has a shelf life of 365 days.
- SKU-030 (Infusion Set Standard) has hazard classification Class 0 (non-hazardous).
- SKU-030 (Infusion Set Standard) is supplied by SUP-06 (Evermoor Packaging Systems).
- SKU-030 (Infusion Set Standard) has a reorder point of 200 units.
