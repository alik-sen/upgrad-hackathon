# SKU-029 Sterile Filter Unit 0.22 um
Summary: SKU-029 Sterile Filter Unit 0.22 um: sterile-device product stored at 15-30°C in sealed packaging, supplier SUP-05.

Facts:
- SKU-029 (Sterile Filter Unit 0.22 um) must be stored at 15-30°C in sealed packaging.
- SKU-029 (Sterile Filter Unit 0.22 um) has a shelf life of 730 days.
- SKU-029 (Sterile Filter Unit 0.22 um) has hazard classification Class 0 (non-hazardous).
- SKU-029 (Sterile Filter Unit 0.22 um) is supplied by SUP-05 (Delmar Industrial Reagents).
- SKU-029 (Sterile Filter Unit 0.22 um) has a reorder point of 200 units.
