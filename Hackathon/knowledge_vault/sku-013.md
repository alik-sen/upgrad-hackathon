# SKU-013 Povidone K30
Summary: SKU-013 Povidone K30: ambient product stored at 15-25°C, supplier SUP-02.

Facts:
- SKU-013 (Povidone K30) must be stored at 15-25°C.
- SKU-013 (Povidone K30) has a shelf life of 540 days.
- SKU-013 (Povidone K30) has hazard classification Class 0 (non-hazardous).
- SKU-013 (Povidone K30) is supplied by SUP-02 (Northgate Chemicals).
- SKU-013 (Povidone K30) has a reorder point of 40 units.
